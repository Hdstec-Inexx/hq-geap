# Tempo de Espera no Atendimento; SLA só no dashboard

O Tempo de Espera é o **intervalo** (em segundos) entre a primeira fala do cliente e a segunda fala do Agente de Voz — a primeira fala do agente é a apresentação e não entra no cálculo; se a sequência ou os timestamps não permitem a diferença, o valor fica ausente. Esse fato persiste no Atendimento (coluna `tme_segundos` / contrato `tme_seconds`) como **integer de segundos** (não como string `min:seg`). TME (média dos Tempos de Espera mensuráveis) **não** é KPI do dashboard nem é materializado na finalização. SLA **não** é materializado na finalização — é KPI do dashboard no período filtrado: % com Tempo de Espera ≤ 150s sobre o **volume** do período (sem medida = fora do prazo), meta de referência 80%. A ingestão, a reconciliação e o reprocessamento derivam o Tempo de Espera com essa regra — não pelo instante absoluto da fala do agente nem pela primeira fala (apresentação).
