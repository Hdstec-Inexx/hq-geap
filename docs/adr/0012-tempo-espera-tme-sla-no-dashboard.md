# Tempo de Espera no Atendimento; TME e SLA só no dashboard

O Tempo de Espera é o **intervalo** (em segundos) entre a primeira fala do cliente e a segunda fala do Agente de Voz — a primeira fala do agente é a apresentação e não entra no cálculo; se a sequência ou os timestamps não permitem a diferença, o valor fica ausente. Esse fato persiste no Atendimento (coluna `tme_segundos` / contrato `tme_seconds`) como **integer de segundos** (não como string `min:seg`); TME e SLA **não** são materializados na finalização — são KPIs do dashboard no período filtrado: TME = média dos Tempos de Espera mensuráveis; SLA = % com Tempo de Espera ≤ 150s sobre o **volume** do período (sem medida = fora do prazo), meta de referência 80%. A ingestão, a reconciliação e o reprocessamento derivam o Tempo de Espera com essa regra — não pelo instante absoluto da fala do agente nem pela primeira fala (apresentação).
